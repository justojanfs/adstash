    Backup & pulihkan

    Data tersimpan di browser ini saja. Ekspor backup secara berkala, terutama sebelum reset browser atau pindah laptop. File .zip berisi semua iklan, media, dan kategori.

    Pembaruan

    Pengecekan hanya mengunduh dua file JSON publik dari GitHub. Tidak ada data iklanmu yang dikirim ke mana pun.

    Aturan skor winning

    Skor = poin yang didapat ÷ poin maksimal dari sinyal yang tersedia × 100, lalu diperkecil bila sinyalnya sedikit. Umur iklan dan jumlah variasi adalah sinyal terkuat; tanpa keduanya label "Tinggi" tidak diberikan (keyakinan rendah). Ubah ambang batas sesuai niche-mu, semua kartu langsung dihitung ulang.
